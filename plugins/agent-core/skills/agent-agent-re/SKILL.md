# Prepare ticket requirements and plan

Identify the target repository, ticket and provider configuration. Read repository instructions and inspect any existing spec artifacts with `workflow-status <spec-directory>`. Treat its output as a presence and status suggestion, not proof of correctness. Preserve existing user files and source identity.

Follow `agent-req`, `agent-plan` and `agent-plan-validate` as needed, reviewing actual ticket evidence, repository research, assumptions and unresolved decisions. Do not implement application code, update external tickets or send messages as a side effect. Report the prepared artifacts and any blockers. This initial workflow does not implement the original automatic orchestration or validate AI-client behavior.
